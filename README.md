# luxury_watch
 luxury watch website inspired by timeless elegance, precision, and Indian craftsmanship. It features immersive 3D visuals, smooth animations, and an interactive user experience.

Features

Interactive 3D watch experience

Smooth scroll animations

Luxury watch collections

Indian heritage-inspired designs

Responsive user interface

Technologies Used

React.js

TypeScript

Vite

Tailwind CSS

CSS3

AI Tools Used

ChatGPT – Idea generation, prompts, coding assistance, and debugging.

Google Flow – Visual content and creative assets.

Gemini – Design ideas and development assistance.

Antigravity – AI-assisted coding and development.

EZGIF – GIF creation and animation editing.

Run Locally

git clone https://github.com/abipoovi/luxury_watch.git
cd luxury_watch
npm install
npm run dev
